🛡️ الموسوعة العربية الشاملة للأمن السيبراني وتيرمكس 🚀

دليلك العملي المتقدم لتعلم الحماية، اختبار الاختراق الأخلاقي، وإدارة أنظمة لينكس

📘 أولاً: كورس الأمن السيبراني الشامل (Cybersecurity)

الأمن السيبراني هو العلم المسؤول عن حماية البنية التحتية الرقمية. ينقسم اختبار الاختراق الأخلاقي (Ethical Hacking) إلى عدة مراحل أساسية يتبعها الخبراء لحماية الأنظمة:

🔍 مراحل اختبار الاختراق الخمسة:

  • 1. جمع المعلومات (Reconnaissance): أهم مرحلة، وتنقسم إلى جمع نشط وخامل لمعرفة كل شيء عن الهدف (أجهزة، إيميلات، ثغرات).
  • 2. الفحص والتحليل (Scanning): استخدام أدوات لفحص المنافذ المفتوحة (Ports) والخدمات النشطة للبحث عن ثغرة.
  • 3. استغلال الثغرات (Gaining Access): مرحلة الدخول إلى النظام باستخدام الثغرة المكتشفة وتطبيق الاختراق.
  • 4. تثبيت الاختراق (Maintaining Access): زرع وسائل خلفية (Backdoors) لضمان الدخول للنظام لاحقاً حتى لو تم قفله.
  • 5. مسح الآثار (Covering Tracks): حذف ملفات السجلات (Logs) لإخفاء أي دليل على عملية الفحص أو الدخول.

🛡️ دليلك العملي لتأمين حساباتك وأجهزتك:

  • تفعيل المصادقة الثنائية (2FA): لا تعتمد على كلمة المرور فقط، فعل 2FA عبر تطبيقات مثل Google Authenticator وليس الرسائل النصية (SMS) لتجنب هجمات SIM Swapping.
  • تجنب صفحات التصيد (Phishing): تأكد دائماً من رابط الموقع (URL) قبل إدخال بياناتك، فالهكر يستخدمون روابط شبيهة جداً مثل faceb00k.com بدلاً من الأصلي.
  • التشفير (Encryption): تأكد من وجود بروتوكول HTTPS وعلامة القفل في المتصفح عند إدخال بيانات حساسة كبطاقات الائتمان.

💻 ثانياً: كورس احتراف تيرمكس (Termux) والأدوات

تيرمكس يمنحك قوة نظام لينكس بالكامل على هاتفك. إليك الأوامر المتقدمة وكيفية تشغيل أشهر أدوات اختبار الاختراق والحماية:

⚙️ كود التهيئة الشامل وتحديث السيرفرات:

اكتب هذا الأمر المدمج لتحديث كل شيء وتثبيت المستودعات الإضافية ولغات البرمجة الأساسية دفعة واحدة:

pkg update && pkg upgrade -y && pkg install git python python2 nodejs php nano wcalc openssh termux-api -y

🛠️ شرح أشهر أدوات الأمن السيبراني وكيفية تثبيتها في تيرمكس:

1. أداة Nmap (لفحص الشبكات والثغرات)

تُستخدم لمعرفة الأجهزة المتصلة بالشبكة والمنافذ المفتوحة وثغرات السيرفرات.

أمر التثبيت والفحص:

pkg install nmap -y nmap scanme.nmap.org
2. أداة Metasploit Framework (العملاق البرمجي للاستغلال)

أضخم منصة تحتوي على آلاف الاستغلاليات الجاهزة لفحص حماية الأنظمة والسيرفرات.

أمر التثبيت (قد يستغرق بعض الوقت بناءً على سرعة الإنترنت):

pkg install metasploit -y msfconsole
3. أداة Sqlmap (لفحص واختراق قواعد البيانات)

أداة شهيرة جداً تستخدم لاكتشاف وفحص ثغرات حقن قواعد البيانات (SQL Injection) في المواقع المصابة.

أمر التثبيت والتشغيل:

git clone https://github.com cd sqlmap python3 sqlmap.py --help

📁 أوامر متقدمة لإدارة الملفات وحماية بيئة عملك:

  • chmod +x [اسم_الأداة] : إعطاء صلاحيات التشغيل التنفيذية لأي أداة تقوم بتحميلها.
  • pwd : طباعة المسار الحالي بالكامل لتعرف في أي مجلد تقف الآن داخل النظام.
  • htop : أداة رائعة لمراقبة معالج ورامات الهاتف والعمليات الشغالة في الخلفية (تُثبت عبر pkg install htop).

👥 من نحن وما هي أهدافنا؟

نحن منصة عربية رائدة متخصصة في التوعية الأمنية الرقمية. نهدف إلى سد الفجوة التعليمية في مجال الأمن السيبراني وأنظمة لينكس للشباب العربي. نقدم هذا المحتوى لأغراض تعليمية وأخلاقية فقط لحمايتك وحماية عائلتك ومجتمعك من الهجمات الرقمية المتطورة.
