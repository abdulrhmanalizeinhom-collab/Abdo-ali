1. بيئة العمل وتحديث السيرفرات (Environment Setup)

التحديث الجذري وتنصيب البيئات الأساسية التهيئة الصفرية

أمر إلزامي موحد لترقية حزم النظام الأساسية وتجهيز لغات البرمجة (Python, PHP, Node.js) لمنع مشاكل الاعتماديات المفقودة أثناء تثبيت الأدوات.

pkg update && pkg upgrade -y && pkg install git python python2 python3 nodejs php nano wget curl -y

صلاحيات الوصول إلى ذاكرة تخزين الهاتف Termux Storage

أمر أساسي لربط مساحة تخزين تيرمكس الداخلية بملفات الهاتف لتسهيل نقل الـ Payloads، التقارير، والملفات المخترقة.

termux-setup-storage

2. الاستخبارات وجمع المعلومات (Information Gathering)

أداة Al-Zaeem الشاملة OSINT Packet

الحزمة البرمجية المتكاملة لجمع معلومات الأهداف الرقمية وفحص الحسابات بشكل مدمج وسريع وبواجهة تفاعلية مرنة [0.1.5، 0.1.6].

git clone https://github.com && cd alzaeem && python2 alzaeem.py

أداة Nmap الذكية Network Recon

العملاق العالمي لتحديد الأجهزة النشطة داخل الشبكة ومعرفة الخدمات النشطة وإصدارات أنظمة التشغيل خلف البورتات المفتوحة.

pkg install nmap -y && nmap --script vuln [Target_IP]
