[+] أساسيات ترمكس وتجهيز البيئة

تحديث النظام وحزم المستودعات

لتحديث ومزامنة مستودعات السيرفرات الرسمية ومنع أخطاء التثبيت.

pkg update && pkg upgrade -y

صلاحية الوصول للذاكرة الداخلية

يسمح لتطبيق ترمكس بقراءة وتعديل وحفظ الملفات على كرت الهاتف.

termux-setup-storage

حزمة تحميل السكربتات (Git)

الأداة المسؤولة عن سحب ونسخ أي مستودع أو أداة من موقع GitHub.

pkg install git -y

بيئة تشغيل بايثون (Python)

تثبيت لغات البرمجة الأساسية لتشغيل ملفات الأدوات ذات الامتداد .py

pkg install python python2 python3 -y

حزمة الشبكات والسيرفرات (Curl/Php)

تثبيت الأدوات المساعدة للاتصال بالروابط وتجهيز الخوادم المحلية.

pkg install php curl wget nano -y
[+] موسوعة أدوات فحص واختبار الاختراق

PhoneSploit Pro

أداة شهيرة لفحص واختبار اختراق أجهزة الأندرويد عن بعد عبر بروتوكول تصحيح الأخطاء ADB.

git clone https://github.com

Al-Zaeem Tool

سكربت عربي متكامل يجمع أكثر من 32 أداة مختلفة لجمع المعلومات وفحص الثغرات الأمنية.

git clone https://github.com

Nmap Scanner

الأداة الأقوى عالمياً لفحص الشبكات، كشف المنافذ المفتوحة (Ports) وتحديد الأنظمة والخدمات.

pkg install nmap -y

Sqlmap

سكربت متقدم لاكتشاف واستغلال ثغرات حقن SQL (SQL Injection) وسحب قواعد بيانات المواقع.

git clone https://github.com

Metasploit Framework

البيئة الضخمة والأشهر عالمياً لإنشاء الثغرات واستغلالها وفحص الأنظمة الأمنية المعقدة.

pkg install metasploit -y
