# يجب تثبيت هذه الأوامر أولاً لتفادي المشاكل داخل التطبيق:

  • pkg update && pkg upgrade -y - تحديث المستودعات وحزم النظام لآخر إصدار.
  • termux-setup-storage - إعطاء ترمكس صلاحية الوصول لذاكرة الهاتف الداخلية.
  • pkg install git -y - تثبيت أداة Git لتحميل السكربتات والمستودعات من GitHub.
  • pkg install python python2 python3 -y - تثبيت لغات بايثون لتشغيل ملفات .py
  • pkg install php curl wget nano -y - تثبيت أدوات سحب الروابط وتعديل النصوص البرمجية.

# أوامر التنقل الأساسية:

# مجالات ومهام فحص الأنظمة الأخلاقي:

  • Information Gathering (جمع المعلومات): المرحلة الأولى والأهم، تستخدم فيها أدوات مثل Nmap و Red Hawk لكشف المنافذ والبيانات المفتوحة.
  • Vulnerability Scanning (فحص الثغرات): البحث عن نقاط الضعف في السيرفرات والمواقع باستخدام سكربتات مخصصة أو أداة sqlmap لحقن قواعد البيانات.
  • Wireless & Network Auditing: فحص ثغرات الشبكات اللاسلكية والتأكد من قوة تشفير المودم والراوتر ضد الهجمات.
  • Social Engineering (الهندسة الاجتماعية): التوعية الأمنية ضد صفحات التصيد والروابط المزورة التي تستهدف وعي المستخدم البشري.

⚠️ تنبيه أمني: يقتصر استخدام هذه المفاهيم والأدوات في أغراض التعليم، والتوعية الأمنية، واختبار اختراق الأنظمة المصرح لك بفحصها فقط.
