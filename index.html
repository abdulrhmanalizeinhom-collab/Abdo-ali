1. حلول المشاكل والتهيئة الأساسية

أمر التحديث الشامل وحل مشكلة المستودعات تحديث رئيسي

أمر متكامل يحل مشكلة توقف سيرفرات تيرمكس، ويقوم بتثبيت اللغات الأساسية (بايثون، بي إتش بي، نود) دفعة واحدة.

termux-change-repo && pkg update && pkg upgrade -y && pkg install git python python2 python3 php nodejs nano wget curl clang -y

حل مشكلة تثبيت حزم بايثون 3 (pip) إصلاح أخطاء

أمر لتحديث أداة تثبيت الحزم لإصلاح مشاكل تعطل الاعتماديات (Requirements) للأدوات الحديثة.

pip install --upgrade pip && pip install setuptools wheel

2. أدوات الكتيب والمستندات المستهدفة

أداة Al-Zaeem الشاملة Multi-Hacking

الموسوعة المدمجة المليئة بأدوات جمع المعلومات، فحص الثغرات، واختبار الاختراق المقسمة برقم الاختيار [0.1.5، 0.1.6].

apt update && apt upgrade -y && apt install git python2 -y && git clone https://github.com && cd alzaeem && python2 alzaeem.py

أداة PhoneSploit Pro Android Controlling

تستخدم لفحص واختبار اختراق هواتف الأندرويد والتحكم بها بالكامل عن بُعد عبر الـ ADB اللاسلكي وتسجيل الكاميرا بشكل حي ومباشر.

git clone https://github.com && cd PhoneSploit-Pro && pip install -r requirements.txt && python phonesploitpro.py

3. جمع الاستخبارات والمعلومات

أداة Red Hawk Web OSINT

سكربت فحص للمواقع يجمع معلومات النطاق، وسجلات الـ DNS، ويكتشف الحماية (Cloudflare) ونوع الخادم وعمليات التحليل الشاملة لبيانات الـ IP.

git clone https://github.com && cd RED_HAWK && php rhawk.php
